# ProxyRules — 手动过滤代理域名名单 (no_cn_domain)
# 在此写入需要强制从代理域名中排除的域名 (一行一个，支持以 # 或 // 开头的注释)
# 被排除的域名将不会出现在 no_cn_domain.txt 规则集中
# 
# 例如:
# +.apple.com

paypal.com
*.paypal.com
+.paypal.com
paypalobjects.com
*.paypalobjects.com
+.paypalobjects.com
paypal.ca
*.paypal.ca
+.paypal.ca
paypal.jp
*.paypal.jp
+.paypal.jp
paypal.me
*.paypal.me
+.paypal.me
paypal.hk
*.paypal.hk
+.paypal.hk
paypal.com.hk
*.paypal.com.hk
+.paypal.com.hk
paypal.com.sg
*.paypal.com.sg
+.paypal.com.sg
